The Whole Idea of QDA

Quadratic Discriminant Analysis (QDA) is a supervised classification method. It models each class as its own independent multi-dimensional probability cloud.

Simple intuition: QDA asks: "Which of these distinct class clouds does this new coordinate fit into best?"

Unlike LDA (which forces every class to share the exact same shape), QDA allows each class to have its own unique spread, stretch, and tilt. This mathematical flexibility is what creates curved boundaries.

QDA Pipeline:

Labeled data → Split Train/Test → Fit class-specific shapes → Score new test coordinates → Make prediction → Evaluate performance

Tiny QDA Dictionary

Feature: An input variable/measurement (e.g., Sweetness, Roundness).

Label / Class: The category we want to predict (e.g., Apple, Pear).

Mean ($\mu$): The center coordinate of a class's data cloud.

Covariance Matrix ($\Sigma$): The learned shape, spread, and tilt of a class cloud.

Prior Probability ($\pi$): The baseline proportion of each class in the dataset.

Mahalanobis Distance: A shape-aware distance metric scaled by a class cloud's variance.

Posterior Probability: The calculated probability that a point belongs to a class after measuring its features.

Discriminant Score ($\delta$): The classification value calculated by QDA; highest score wins.

Regularization: Adding a small constant diagonal shift to stabilize covariance estimation.

Prior Probability Controls Apples ($N_A$): 80 Pears ($N_B$): 80

Covariance Matrix Anatomy

For our two features, the 2x2 Covariance Matrix is represented as:

$\Sigma = \begin{pmatrix} \text{Variance}(X_1) & \text{Covariance}(X_1, X_2) \\ \text{Covariance}(X_1, X_2) & \text{Variance}(X_2) \end{pmatrix}$

Diagonal entries: Represent the independent spread of Sweetness and Roundness.
Off-diagonal entries: Represent the relationship. A positive value means sweeter fruit is generally rounder, creating a diagonal tilt!

Determinants & Inverses

The Determinant ($|\Sigma_k|$): Is a covariance-volume scaling factor. Its square root, $\sqrt{|\Sigma_k|}$, corresponds more closely to geometric area or volume.

The Inverse ($\Sigma_k^{-1}$): Acts as a scaling standardizer. It mathematically divides distances by the variance in that specific direction so wide directions aren't artificially penalized.

The decision boundary is defined mathematically as the curve where the score for Apples exactly equals the score for Pears:

$\delta_{\text{Apple}}(x) = \delta_{\text{Pear}}(x)$

Because the covariance matrices $\hat{\Sigma}_{\text{Apple}} \neq \hat{\Sigma}_{\text{Pear}}$, the quadratic terms in the equation do not cancel. The boundary naturally curves to encapsulate the unique shape characteristics of each class.

A class covariance can be unstable or singular when there are few observations relative to features. Adding a small positive multiple of the identity improves invertibility but does not make unequal class covariances equal. Shrinking every class covariance toward the same pooled covariance creates a path toward LDA. The lab uses pooled shrinkage and a small numerical diagonal floor; the two interventions have different roles. Select the amount with validation, not the final test.

When QDA Thrives:

  • Classes have completely different shapes and orientations.
  • The dataset is large enough to estimate parameters reliably.
  • Boundaries are naturally curved.

When QDA Struggles:

  • Extremely small datasets (leads to overfitting and singular matrices).
  • Datasets with many features (parameter explosion).
  • Outliers present that distort covariance matrix estimation.

Alternatives to QDA:

  • LDA: If dataset is small or class spreads are similar.
  • Logistic Regression: If you prefer to model class boundaries without making Gaussian distribution assumptions.
  • KNN or SVM: If decision boundaries are highly complex or non-Gaussian.
