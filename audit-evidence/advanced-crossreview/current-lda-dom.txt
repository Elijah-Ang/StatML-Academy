- heading "The Whole Idea of LDA" [level=3]
- paragraph:
  - strong: Linear Discriminant Analysis (LDA)
  - text: is a supervised classification method. It uses labeled examples to learn a straight-line rule that separates classes.
- paragraph:
  - strong: "Simple Idea:"
  - text: "LDA looks for a direction (projection axis) where:"
  - text: • Different class centers are as
  - strong: far apart
  - text: as possible.
  - text: • Points inside each class are as
  - strong: tightly bunched (low spread)
  - text: as possible.
- strong: "LDA General Pipeline:"
- text: Labeled Data → Class Centers → Class Spread → Optimal Direction → Boundary → Prediction
- paragraph: "\"LDA is like looking at a messy 2D cloud of points from the best angle so the two groups look as separated as possible.\""
- heading "Tiny LDA Dictionary" [level=3]
- strong: "Feature:"
- text: A measurement used to make a prediction (e.g., Sweetness or Color).
- strong: "Label:"
- text: The known category of an example (e.g., Apple or Orange).
- strong: "Class:"
- text: The target group we want to predict (Apple class or Orange class).
- strong: "Mean (μ):"
- text: The average position or center of a class point cloud.
- strong: "Variance:"
- text: How much a single feature fluctuates.
- strong: "Covariance:"
- text: How two features move in relation to each other.
- strong: "Scatter (S):"
- text: A mathematical measure of data spread or messiness.
- strong: "Projection:"
- text: Squashing 2D coordinates down onto a single 1D axis.
- strong: "Discriminant Score (δ):"
- text: A numerical score LDA computes for each class; the highest score wins!

- heading "Choosing Good Features" [level=2]: Choosing Good Features
- paragraph: Not every measurement helps separate classes. We pick features where the groups actually show different patterns — like Sweetness and Color Score.
- paragraph: Bad features (random IDs, row numbers) add noise without signal. LDA works best when features genuinely explain class differences.

- paragraph:
  - text: •
  - strong: "Sweetness:"
  - text: In this toy dataset, the two fruit groups show different sweetness patterns.
- paragraph:
  - text: •
  - strong: "Color Score:"
  - text: In this toy dataset, apples and oranges have different color score patterns.
- paragraph:
  - text: •
  - strong: "Row Number:"
  - text: Completely meaningless for classification.
- paragraph:
  - text: •
  - strong: "Day of Entry:"
  - text: No predictive power.
- paragraph:
  - strong: "Warning:"
  - text: Bad or irrelevant features can seriously confuse LDA because they add noise to the calculated means, covariances, and final decision boundary.

- heading "The Shared Covariance Assumption" [level=2]: The Shared Covariance Assumption
- paragraph:
  - text: Here's LDA's
  - strong: key assumption
  - text: ": all classes share the same covariance shape. The groups can have different centers, but their spread is assumed to be roughly the same."
- paragraph:
  - text: So LDA
  - emphasis: pools
  - text: the individual covariance matrices into one shared estimate. Watch the ellipses morph into a single shape.
- heading "Pooled Covariance Matrix Σ" [level=3]
- text: Σ = S_W / (n − 2) Σ = ⎡ 0.482 0.147 ⎤ ⎣ 0.147 0.476 ⎦
- heading "Why does LDA pool covariance?" [level=3]
- paragraph:
  - text: LDA assumes that the classes have similar spread shapes. Instead of keeping separate shapes for Apple and Orange, it combines them into
  - strong: one shared covariance estimate
  - text: .
- paragraph:
  - strong: "Simple meaning:"
  - text: Different centers, same general spread shape.
- strong: "LDA vs. QDA Comparison:"
- text: •
- strong: "LDA (Linear):"
- text: Assumes shared covariance → Draws a
- strong: straight
- text: decision line.
- text: •
- strong: "QDA (Quadratic):"
- text: Allows different covariances per class → Can draw a
- strong: curved
- text: decision line.
- paragraph:
  - strong: "Warning:"
  - text: If the class clouds actually have very different shapes, LDA's shared covariance assumption is violated. LDA may struggle, and QDA (Quadratic Discriminant Analysis) might fit the data much better.

- heading "Between-Class Scatter" [level=2]: Between-Class Scatter
- paragraph:
  - text: S
  - subscript: B
  - text: measures how far apart the class centers are. The further apart, the easier it is for LDA to separate them.
- paragraph:
  - text: LDA's goal is to
  - strong: maximize the ratio
  - text: "of between-class scatter to within-class scatter:"
- heading "Between-class scatter = gap between class centers" [level=3]
- paragraph:
  - text: "Let's contrast the two scatter metrics:"
  - text: •
  - strong: "Within-class scatter asks:"
  - text: "\"How messy and spread out is each class"
  - emphasis: inside
  - text: itself?"
  - text: •
  - strong: "Between-class scatter asks:"
  - text: "\"How far apart are the class centers (means)?\""
- paragraph:
  - strong: "LDA's Ultimate Goal:"
  - text: We want the gap between classes to be
  - strong: BIG
  - text: ", and the messiness inside each class to be"
  - strong: SMALL
  - text: "!"
- text: "J(w) = wᵀ S_B w / wᵀ S_W w In simple terms, J(w) is maximized when: 1. Projected class means are far apart. 2. Projected class spreads are small."
- heading "Between-Class Scatter SB" [level=3]:
  - text: Between-Class Scatter S
  - subscript: B
- text: S_B = (n₁·n₂/n) · (μ₁ − μ₂)(μ₁ − μ₂)ᵀ S_B = ⎡ 77.224 107.485 ⎤ ⎣ 107.485 149.604 ⎦

- heading "What is projection and why do we do it?" [level=3]
- paragraph:
  - strong: Projection
  - text: means dropping every 2D point (Sweetness, Color) down onto a single 1D line or direction.
- paragraph:
  - text: This turns a 2D pair of numbers into a
  - strong: single 1D score
  - text: ":"
- generic: Fruit (Sweetness, Color) → [Project] → One LDA Score
- paragraph:
  - strong: Why project?
  - text: If the projected Apple scores sit neatly on one side of the line and the projected Orange scores sit on the other side, LDA has found an excellent direction for separation!
- text: w ∝ S_W⁻¹ (μ₁ − μ₂) This isn't just the straight line between means. It also tilts to avoid the direction of maximum within-class spread.
- heading "Optimal Direction w" [level=3]
- text: w = S_W⁻¹ · (μ₁ − μ₂) → [ 0.4594, 0.8883 ]
- paragraph: This direction maximizes the Fisher criterion J(w). Points projected onto it show maximum class separation.

- heading "What are priors (π_k)?" [level=3]
- paragraph:
  - text: The
  - strong: prior probability (π_k)
  - text: represents how common a class is in our training data.
  - text: • If apples and oranges are equally common, priors are equal (50% each).
  - text: • If we have 90% apples in training, the apple score gets a prior boost, shifting the boundary slightly to favor Apple predictions.
- text: δ_k(x) = xᵀ Σ⁻¹ μ_k − ½ μ_kᵀ Σ⁻¹ μ_k + log(π_k) Predict class k with the highest δ_k(x)
- heading "Decision Rule" [level=3]
- text: Prior π_apple = 0.50
- text: Prior π_orange = 0.50
- paragraph: The boundary is where δ_apple(x) = δ_orange(x). Points on the apple side get a higher apple score.

- heading "Assumptions & Limitations" [level=2]: Assumptions & Limitations
- paragraph: To use LDA effectively, you need to understand when it thrives and when it falls short.
- heading "LDA Works Best When:" [level=3]
- list:
  - strong: "Linearity:"
  - text: A straight-line boundary is a reasonable way to separate classes.
  - strong: "Normality:"
  - text: Each class looks like a symmetrical oval cloud (multivariate normal distribution).
  - strong: "Equal Spread:"
  - text: All classes share roughly the same spread/covariance shape.
  - strong: "Independence:"
  - text: Data samples are collected independently.
  - strong: "Data Volume:"
  - text: There are many more rows than features.
  - strong: "No Outliers:"
  - text: Extreme values are absent (outliers pull means away easily).
- heading "LDA Struggles When:" [level=3]
- list:
  - listitem: The true dividing boundary is highly curved.
  - listitem: Classes have very different shapes or spreads (e.g., one is a tight circle, the other is a giant flat ellipse).
  - listitem: There are severe outliers that skew centers.
  - listitem: You have too many features and not enough rows (overfitting).
  - listitem: Features are redundant or highly correlated (collinearity).
- heading "Alternative Methods" [level=3]
- paragraph: "If LDA doesn't fit, consider these standard alternatives:"
- strong: "QDA (Quadratic Discriminant Analysis):"
- text: Excellent if class spreads are highly unequal.
- strong: "Logistic Regression:"
- text: Better if you need direct probabilities and fewer statistical assumptions.
- strong: "KNN or Decision Trees:"
- text: Great for highly complex, non-linear boundaries.
- generic: Complete the picture
- heading "Posterior probabilities and regularised LDA" [level=3]
- paragraph: The discriminant scores can be converted into posterior class probabilities. These probabilities are useful for ranking and threshold decisions, not merely producing a hard label.
- paragraph: When the covariance estimate is unstable because there are many features or limited data, shrinkage or regularised LDA can trade a little bias for much lower variance.
