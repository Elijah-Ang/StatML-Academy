Stage 01 · Observe

Points, labels, and a decision boundary

Each point is one labelled training row with two features. Colour marks the class. A classifier needs a rule that places a future point on one side or the other.

f(x) > 0  →  Class +1
f(x) < 0  →  Class −1

In two dimensions the boundary is a line. In three dimensions it is a plane. Beyond that, it becomes a hyperplane, a dramatic name for the same separating idea.

The plot uses two features because humans remain tragically dependent on visible space. The model itself can work with many features.
Stage 02 · Question

Why not choose any separating line?

When the classes are separable, several lines can classify every training point correctly. Training accuracy alone cannot tell us which line is safer.

Narrow clearance

Fits the training rows, but a small measurement change can flip a prediction.

Wide clearance

Leaves more room before the nearest point crosses the boundary.

A linear SVM adds a preference: choose the separator with the greatest distance to the closest points from either class.

Quick check: what extra criterion does SVM use?
It chooses the separating line with the largest margin, subject to the model’s allowance for violations.
Stage 03 · Understand

The margin is protected space

The margin is the gap between two parallel support planes touching the closest training points on each side.

Boundary: wᵀx + b = 0
Margin boundaries: wᵀx + b = +1 and −1
Geometric margin width = 2 / ‖w‖

Maximising the margin is equivalent to keeping the weight vector small while still satisfying the classification constraints.

A wide margin can make the separator less sensitive. It cannot rescue biased data, leakage, poor labels, or a mismatched kernel. Geometry is useful, not divine intervention.
Stage 04 · Focus

Support vectors are the points that matter most

Support vectors lie on or inside the margin. They directly constrain the fitted boundary.

f(x) = Σᵢ αᵢ yᵢ K(xᵢ, x) + b
Only rows with αᵢ > 0 are support vectors.

Move a distant, safely classified point a little and the boundary may not change. Move a support vector and the solution can shift immediately.

Important distinction: “support vector” means the row constrains this fitted margin. It does not mean the row is causally or commercially important in every possible sense.
Stage 05 · Relax

Hard margins break when reality overlaps

A hard-margin SVM demands perfect separation with every row outside the margin. Real classes overlap, labels contain errors, and outliers appear because datasets enjoy sabotage.

A soft-margin SVM introduces slack variables ξᵢ so violations are allowed but penalised.

yᵢ(wᵀxᵢ + b) ≥ 1 − ξᵢ,  with ξᵢ ≥ 0
SlackMeaning
ξ = 0Correct and on or beyond the margin
0 < ξ ≤ 1Correct side, but inside the margin
ξ > 1Misclassified
Stage 06 · Tune

C decides how expensive violations are

minimise  ½‖w‖² + C Σᵢ ξᵢ

Small C

Violations are cheaper. The model accepts more errors to preserve a wider, smoother margin.

Large C

Violations are expensive. The model fits training rows more aggressively, often with a narrower margin.

C is an inverse regularisation parameter: larger C means less regularisation.

A huge C does not mean “more accurate”. It means “punish training violations more”, which can also mean “memorise the noise with confidence”.
Stage 07 · Prepare

Scale features before comparing distances

SVM geometry uses dot products and distances. A feature ranging from 0 to 100,000 can dominate another ranging from 0 to 1, even when the smaller-scale feature is genuinely informative.

standardised value = (value − training mean) ÷ training standard deviation

Fit the scaler inside each training fold, then apply that fitted transformation to validation, test, and production rows.

Two distinct failures: scaling before the split leaks information; scaling the test set separately changes the coordinate system. Both are wrong in impressively different ways.
Stage 08 · Formalise

Hinge loss ignores easy correct points

hinge loss = max(0, 1 − y × f(x))
Signed margin y f(x)LossInterpretation
≥ 10Correct and safely beyond the margin
0 to 1positiveCorrect but inside the margin
≤ 0≥ 1Misclassified

Once a point is correctly beyond the margin, its hinge loss is zero. Distant easy points stop pulling the boundary.

Quick check: y f(x) = 1.7. What is the loss?
max(0, 1 − 1.7) = 0.
Stage 09 · Interpret

The decision score is not automatically a probability

The decision function reports which side of the boundary a row occupies and how strongly it lies in that direction.

larger positive f(x) → stronger Class +1 decision
larger negative f(x) → stronger Class −1 decision

For a linear SVM, the score relates to signed distance after accounting for ‖w‖. For a kernel SVM, treat it as a boundary score rather than literal distance in the original plot.

f(x) = 2 does not mean 200%, nor twice the probability of f(x) = 1. Probability estimates require a separate calibration model fitted with held-out predictions.
Stage 10 · Extend

A straight boundary cannot solve every pattern

Imagine one class forming an inner cluster and another forming an outer ring. No straight line can separate them in the original two-feature space.

A transformed feature such as squared radius can reveal the structure:

r² = x₁² + x₂²

In transformed space, a simple threshold on r² can separate inner from outer points. A curved boundary in the original plot can still correspond to a linear rule elsewhere.

Stage 11 · Kernelise

The kernel trick avoids explicit feature explosion

A kernel computes similarities that behave like inner products in a richer feature space, without explicitly constructing every transformed coordinate.

K(x, z) = φ(x)ᵀφ(z)

RBF: K(x,z) = exp(−γ ‖x − z‖²)

Small gamma

Each point has broad influence. The decision surface changes slowly.

Large gamma

Influence becomes local. The boundary can wrap tightly around training points.

Large gamma plus large C can create an intricate boundary that remembers noise instead of learning structure.
Stage 12 · Validate

Tune the whole pipeline inside cross-validation

Kernel, C, gamma, class weights, and preprocessing are hyperparameters. Choose them using validation folds inside the development data.

Pipeline(StandardScaler(), SVC())
GridSearchCV(C, gamma, kernel, scoring)
Create an untouched final test set when the dataset is large enough.
Fit scaling and feature processing inside each training fold.
Score candidate settings using a metric aligned with the task.
Refit on all development data, then evaluate once on the test set.
Search C and gamma on logarithmic scales. If the winner sits at the edge, extend the range rather than declaring the boundary divinely optimal.
Stage 13 · Evaluate

Measure the errors the problem actually cares about

Accuracy alone can hide minority-class failures. Use confusion matrices, per-class recall, and precision–recall analysis when the positive class is rare.

Class imbalance

Consider class weights when minority-class mistakes deserve a larger penalty.

Operational thresholds

Tune the decision threshold on validation data when the default boundary is unsuitable.

Calibration

Map held-out SVM scores to probabilities using sigmoid, isotonic, or another calibration method.

Multiclass

Combine binary models using one-vs-rest or one-vs-one decisions.

One-vs-one classifiers: K(K−1)/2
One-vs-rest classifiers: K
A calibrated 0.8 has a frequency meaning: among cases assigned about 0.8, roughly 80% should belong to that class. Raw margin scores make no such promise.

Limits

Each point’s influence becomes very local, enabling an irregular boundary and increasing overfitting risk.
