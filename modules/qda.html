Imagine sorting fruit into Apples and Pears based on two measurements: Sweetness ($X_1$) and Roundness ($X_2$).

The Whole Idea of QDA

Quadratic Discriminant Analysis (QDA) is a supervised classification method. It models each class as its own independent multi-dimensional probability cloud.

Simple intuition: QDA asks: "Which of these distinct class clouds does this new coordinate fit into best?"

Unlike LDA (which forces every class to share the exact same shape), QDA allows each class to have its own unique spread, stretch, and tilt. This mathematical flexibility is what creates curved boundaries.

QDA Pipeline: Labeled data → Split Train/Test → Fit class-specific shapes → Score new test coordinates → Make prediction → Evaluate performance

Tiny QDA Dictionary

Feature: An input variable/measurement (e.g., Sweetness, Roundness).

Label / Class: The category we want to predict (e.g., Apple, Pear).

Mean ($\mu$): The center coordinate of a class's data cloud.

Covariance Matrix ($\Sigma$): The learned shape, spread, and tilt of a class cloud.

Prior Probability ($\pi$): The baseline proportion of each class in the dataset.

Mahalanobis Distance: A shape-aware distance metric scaled by a class cloud's variance.

Posterior Probability: The calculated probability that a point belongs to a class after measuring its features.

Discriminant Score ($\delta$): The classification value calculated by QDA; highest score wins.

Regularization: Adding a small constant diagonal shift to stabilize covariance estimation.

Stage 02

Train / Test Split

To perform proper Machine Learning, we cannot estimate our model and test its performance on the same data points. This is known as Data Leakage.

The Rules of the Split:

  • Training Set (80%): Used exclusively to calculate Class Priors, Means, and Covariance Matrices.
  • Test Set (20%): Hidden away completely during the learning phase. Used only for final model evaluation.
Warning: Including testing data in your mean or covariance calculations will falsely inflate performance metrics, making you think your model generalizes better than it actually does!

Stage 03

The Straight-Line Trap (LDA)

The simplest approach is Linear Discriminant Analysis (LDA). It draws a straight boundary to separate the groups.

To do this, LDA calculates the pooled average shape of all the data and forces both groups to share that exact same covariance matrix ($\hat{\Sigma}_{shared}$).

The Limitation: Look at the dotted ellipses on the canvas. Because LDA forces them to be identical in shape and tilt, it misclassifies points near the edges. It completely ignores the unique diagonal stretch of the Pears.

Stage 04

Fitting QDA: What the Model Learns

To fit QDA, we estimate three key statistical parameters directly from our training set for each class $k$:

Covariance Matrix Anatomy

For our two features, the 2x2 Covariance Matrix is represented as:

$\Sigma = \begin{pmatrix} \text{Variance}(X_1) & \text{Covariance}(X_1, X_2) \\ \text{Covariance}(X_1, X_2) & \text{Variance}(X_2) \end{pmatrix}$

Diagonal entries: Represent the independent spread of Sweetness and Roundness.
Off-diagonal entries: Represent the relationship. A positive value means sweeter fruit is generally rounder, creating a diagonal tilt!

Determinants & Inverses

The Determinant ($|\Sigma_k|$): Is a covariance-volume scaling factor. Its square root, $\sqrt{|\Sigma_k|}$, corresponds more closely to geometric area or volume.

The Inverse ($\Sigma_k^{-1}$): Acts as a scaling standardizer. It mathematically divides distances by the variance in that specific direction so wide directions aren't artificially penalized.

Stage 05

Testing with Shape-Aware Distance

Euclidean distance only measures straight-line distance. It assumes classes are perfect, un-tilted circles.

QDA uses Mahalanobis Distance, which measures distance in units of class-specific standard deviations, aligning with the class's natural stretch and tilt.

Try it: Tap and drag on the canvas to reposition the test probe. Look at the contour lines of equal distance wrapping around each class mean.

A Note on Posterior Probabilities

The posteriors are calculated assuming the features are strictly normally (Gaussian) distributed. If your real-world data is heavily skewed or multimodal, the model's confidence scores will be poorly calibrated!

Stage 06

The Curved Boundary

The decision boundary is defined mathematically as the curve where the score for Apples exactly equals the score for Pears:

$\delta_{\text{Apple}}(x) = \delta_{\text{Pear}}(x)$

Because the covariance matrices $\hat{\Sigma}_{\text{Apple}} \neq \hat{\Sigma}_{\text{Pear}}$, the quadratic terms in the equation do not cancel. The boundary naturally curves to encapsulate the unique shape characteristics of each class.

Stage 09

Regularization & Shape Playground

When class distributions are close or contain few data points, the empirical covariance matrices can become unstable or singular (zero determinant), causing inverse division errors.

To solve this, we add a regularization ridge ($\lambda$) directly to the diagonals of the covariance matrices:

Regularisation depends on its target. A class covariance can shrink toward a diagonal matrix, an identity matrix, or a shared pooled covariance. Only shrinkage toward the shared covariance moves QDA directly toward LDA. Choose both target and amount through validation or cross-validation.

$\Sigma_{\text{regularized}} = \Sigma + \lambda I$
Regularization Control
0.10

Low Ridge (0.0): Maximum flexibility, but highly sensitive to noise and singularity.
High Ridge (1.5): Increases stability, squeezing matrices to be circular. The curved boundary smooths out, behaving more like LDA!

Stage 10

Assumptions, Complexity & Synthesis

Every algorithm is a balance of flexibility and parameters. QDA estimates a separate covariance matrix for each class, which comes at a significant parameter cost.

When QDA Thrives:

  • Classes have completely different shapes and orientations.
  • The dataset is large enough to estimate parameters reliably.
  • Boundaries are naturally curved.

When QDA Struggles:

  • Extremely small datasets (leads to overfitting and singular matrices).
  • Datasets with many features (parameter explosion).
  • Outliers present that distort covariance matrix estimation.

Alternatives to QDA:

  • LDA: If dataset is small or class spreads are similar.
  • Logistic Regression: If you prefer to model class boundaries without making Gaussian distribution assumptions.
  • KNN or SVM: If decision boundaries are highly complex or non-Gaussian.
