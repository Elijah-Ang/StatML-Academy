Missing Data & Encoding

Treat missingness and categories as modelling choices, not housekeeping.

Stage 01

The problem

Missing values and categories carry structure. A convenient fill value or numeric code can change the estimand, introduce false order, or leak outcome information.

Stage 02

Intuition and objective

Imputation predicts or substitutes missing values; encoding represents categories numerically. Both are learned transformations and belong inside the pipeline.

Stage 03

Worked example

Income is missing more often for high earners. Mean imputation pulls their values toward the centre and understates variation. A missingness indicator may help prediction, but it does not make the missing-at-random assumption true for inference.

Stage 04

Reasoning with the method

MCAR, MAR and MNAR are assumptions about the missingness process, not labels that a plot can prove. Complete-case analysis is valid for limited targets under restrictive conditions. Single imputation treats filled values as known and usually understates inferential uncertainty; multiple imputation combines within- and between-imputation variation. Encoding defines geometry: one-hot separates unordered levels, ordinal encoding asserts order, and target encoding borrows outcome information. Target and frequency encoders need fold-safe fitting and an unseen-level policy. Raw columns and a data dictionary should be retained so every transformation remains auditable.

A defensible analysis connects the mathematical target to the real decision. Identify what is estimated, which observations contribute independent information, what choices are learned from data, and which uncertainty remains after fitting. Then ask how the conclusion would change under another reasonable sample, a plausible alternative specification, or a shift in the deployment population. This reasoning must happen before the final test set is opened. The test result evaluates the locked procedure; it does not choose that procedure. Sensitivity analysis is most useful when it is planned around credible failure modes rather than used to search for a preferred answer.

Stage 05

Interactive laboratory

Change missingness rate and strategy. Compare remaining bias, predictive error and whether an encoding introduces artificial order.

Stage 06

Assumptions and failure modes

Assumptions

Missing-data methods rely on assumptions about why values are absent. Category encodings assume a structure—unordered, ordinal, or target-related—that must be defensible.

When the method fails

Single imputation understates inferential uncertainty; ordinal codes create fake distances; target encoding leaks without cross-fitting; unseen categories can break deployment.

Stage 07

Practical workflow

  1. Profile missingness and category levels
  2. Separate structural from accidental missingness
  3. Split data before fitting transforms
  4. Choose imputation for the analysis goal
  5. Encode with explicit reference and unknown-level policy
  6. Run sensitivity analyses

Stage 08

Interpretation and reporting

What to report: Report missingness rates, mechanism assumptions, imputation model, number of imputations, encoding, reference levels, unknown-category policy and sensitivity.

Common misuse: Using zero as “missing” when zero has a real scientific meaning.

Stage 09

Knowledge checks

Target encoding should be…

Answer and explanation

Cross-fitted inside training data. Each held-out row must not influence its own encoded target mean.

Single imputation for inference often…

Answer and explanation

Understates uncertainty. Treating filled values as known ignores imputation uncertainty.

Integer codes for unordered colours create…

Answer and explanation

Artificial order and distance. Codes such as red=1, blue=2, green=3 imply geometry that may not exist.

An unseen category policy belongs…

Answer and explanation

In the fitted pipeline. Deployment must define how new levels are represented.

A missingness indicator…

Answer and explanation

May help prediction but does not prove a missingness mechanism. It is a feature, not a proof about why data are absent.
