Stage 01

The problem

A model produces many kinds of errors. A metric turns those errors into a comparison, but only after the real decision defines what matters. A hospital triage model and a spam filter should not inherit the same priorities by convenience.

Stage 02

Intuition and objective

MAE counts absolute regression misses in outcome units; RMSE gives large misses extra weight. Accuracy counts correct labels, precision asks how many predicted positives were right, and recall asks how many actual positives were found. Log loss and Brier score evaluate probabilities, while calibration compares predicted risks with observed frequencies.

Stage 03

Worked example

A screening model sees 1,000 people: 100 have disease. It finds 80 of them and falsely flags 90 healthy people. TP=80, FN=20, FP=90, TN=810. Accuracy is 89%, recall is 80%, and precision is 47%. The apparently healthy accuracy hides that more than half of alerts are false.

Stage 04

Reasoning with the method

MAE targets absolute error in outcome units, while squared-error optimisation gives large misses extra weight. Accuracy summarises a thresholded confusion matrix; precision, recall and specificity condition on different denominators. ROC-AUC measures ranking across thresholds, whereas PR-AUC emphasises positive retrieval and depends on prevalence. Log loss and Brier score evaluate probabilities, and calibration asks whether predicted risks match observed frequencies. Out-of-sample R² compares with a mean-prediction baseline and may be negative. With asymmetric consequences, write expected cost explicitly and choose the threshold that supports the actual decision and operational capacity.

A defensible analysis connects the mathematical target to the real decision. Identify what is estimated, which observations contribute independent information, what choices are learned from data, and which uncertainty remains after fitting. Then ask how the conclusion would change under another reasonable sample, a plausible alternative specification, or a shift in the deployment population. This reasoning must happen before the final test set is opened. The test result evaluates the locked procedure; it does not choose that procedure. Sensitivity analysis is most useful when it is planned around credible failure modes rather than used to search for a preferred answer.

Stage 05

Interactive laboratory

Move the decision threshold. Watch the confusion matrix, precision, recall and expected error cost change together.

Stage 06

Assumptions and failure modes

Assumptions

The evaluation sample must represent the deployment population, labels must be trustworthy, and each metric must be calculated on genuinely held-out predictions.

When the method fails

Accuracy fails under imbalance or unequal costs. MAPE behaves badly near zero. ROC-AUC can obscure performance at the operating region, and a strong ranking score does not guarantee calibrated probabilities.

Stage 07

Practical workflow

  1. Define the decision and error costs
  2. Choose primary and secondary metrics before model comparison
  3. Tune model and threshold on validation data
  4. Lock the full pipeline
  5. Report final test metrics with bootstrap or repeated-sample intervals

Stage 08

Interpretation and reporting

What to report: State the metric definition, threshold, prevalence or outcome scale, baseline, point estimate, uncertainty interval and real-world costs.

Common misuse: Selecting whichever metric makes a preferred model look best after seeing the results.

Stage 09

Knowledge checks

False negatives are extremely costly. Which metric deserves priority?

Answer and explanation

Recall. Recall measures the fraction of actual positives found; the cost requirement makes missed positives central.

Why can 99% accuracy be useless?

Answer and explanation

The positive class may be only 1% and never detected. A classifier predicting every case negative can be 99% accurate and have zero recall.

Which quantity evaluates probability calibration?

Answer and explanation

Brier score. Brier score measures squared probability error and is sensitive to calibration.

What belongs on the final test set?

Answer and explanation

One evaluation of the locked model and threshold. All choices must be locked before the test evaluation.

What should accompany a metric?

Answer and explanation

Uncertainty and a relevant baseline. A point estimate needs context, comparison and sampling uncertainty.
