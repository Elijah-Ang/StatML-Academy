# Mobile QA — 8 September 2026

## Scope

The landing page and all 33 existing modules, comprising 359 lesson sections.
Phone viewports: 320 × 740, 360 × 740, 390 × 844, and 430 × 844.
Each section is visited in order; reverse scrolling is checked in every module.
Additional checks cover touch navigation, tablet-sized landing layout (768 × 1024), and rotation of all modules to 844 × 390 and back.
These are Chrome browser emulations, not physical iOS/Safari device tests.

## Changes

- Preserve the mobile space theme with a drawn sun, UFO and comet, gentle motion, and lines connecting the existing tappable module symbols.
- Link all 33 existing lessons from the mobile map, including ten previously unlisted companion lessons within the existing subject groups.
- Select diagrams at a shared reading position below the pinned visual. Long sections no longer need to meet desktop intersection thresholds.
- Measure the illustration height for section anchors and remove fixed desktop-sized gaps on phones.
- Redraw legacy canvases when their actual container changes size, including after rotation or font loading.
- Keep ANOVA tables accessible by horizontal scrolling, separate hierarchical-clustering instruments, preserve K-means plot height, and contain the QDA formula and tooltip.
- Replace Polynomial Regression's fixed viewport subtraction with a readable canvas size; size Model Selection's canvas to its available sheet.
- Use natural scrolling for the visual in short landscape viewports. Preserve reduced-motion support.

Teaching content, examples, statistical calculations, section order, and the original Neural Networks illustrations are preserved. Mobile presentation and navigation links are updated.

## Verification

The four-width section sweep passed: **132 module/viewport combinations, 1,436 section visits, zero page errors**. Touch controls, all 33 module rotations, desktop regressions, existing interactive tests, and the production build also passed.

- `npm run test:mobile`: all sections at four phone widths, reverse scrolling, active-stage synchronization, heading visibility, page overflow, errors, mobile map links, menu anchors, touch controls, enlargement, and rotation.
- `npm run test:paper`: all 34 pages on desktop and phone, with quiz and CV controls.
- `npm run test:sketch`: all 24 Deep Learning / Naive Bayes scenes, numeric examples, original Neural Networks controls, keyboard access and reduced motion.
- `npm test`: statistical content/local links and Logistic Regression workflow.
- `npm run build`: static production output.
