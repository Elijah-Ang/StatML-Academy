- heading "The Whole Idea of Classification Trees" [level=3]:
  - text: The Whole Idea of Classification Trees
- paragraph:
  - text: A
  - strong: Classification Tree
  - text: is a supervised machine-learning model that learns a sequence of simple yes/no flowchart-like questions to sort data into categories.
- generic: Raw Labeled Data → Root Node → Scan Best Question → Split Data → Repeat Recursively → Leaf Prediction → Evaluation
- heading "Tiny Tree Dictionary" [level=3]:
  - text: Tiny Tree Dictionary
- strong: "• Feature:"
- text: A measurable property or input variable used to make predictions (e.g., Weight, Color Intensity).
- strong: "• Label:"
- text: The target outcome or true answer we want the model to predict (e.g., Apple, Orange).
- strong: "• Class:"
- text: One of the specific categorical outcomes (e.g., Apples vs. Oranges).
- strong: "• Root Node:"
- text: The very first top-level block containing 100% of the training data.
- strong: "• Split:"
- text: A division of a parent node into two child nodes based on a feature question.
- strong: "• Child Node:"
- text: The subgroups created after splitting a parent node.
- strong: "• Leaf Node:"
- text: A final terminal node that does not split further. It makes the final prediction.
- strong: "• Impurity:"
- text: A measure of how mixed or diverse the class labels are within a particular node.
- strong: "• Gini Impurity:"
- text: A mathematical metric used to calculate impurity (0.0 means perfectly pure; 0.5 is the maximum for a balanced binary node).
- strong: "• Weighted Impurity:"
- text: The combined impurity of child nodes, weighted by the proportion of samples that went into each child.
- strong: "• Impurity Decrease:"
- text: The difference between parent Gini and weighted child Gini. The tree maximizes this "gain".
- strong: "• Decision Boundary:"
- text: The geometric line(s) dividing different class zones on the coordinate map.
- strong: "• Tree Depth:"
- text: The length of the longest path from the root node down to any leaf node.
- strong: "• Pruning:"
- text: Cutting back branches to simplify the model and improve generalizability on unseen data.
- strong: "• Overfitting:"
- text: Memorizing noise in the training set, causing failure on unseen test data.
- strong: "• Underfitting:"
- text: Creating a model that is too simple (e.g. too shallow) to learn the real underlying patterns.

- heading "Gini Impurity vs. Entropy" [level=3]:
  - text: Gini Impurity vs. Entropy
- paragraph:
  - text: While Gini is highly popular in CART (Classification and Regression Trees), another metric called
  - strong: Entropy
  - text: "is also widely used:"
- generic: Entropy = - Σ pᵢ log₂(pᵢ)
- paragraph: "Both metrics measure the same core property: disorder. A node with equal proportions of classes has a Gini score of 0.50 and an Entropy score of 1.0. Both reach 0.0 when a node is perfectly pure. In practice, Gini and entropy often choose very similar splits, but not always. This guide uses Gini because it is simple, common, and easy to compute."

- heading "The Candidate Search Strategy" [level=3]:
  - text: The Candidate Search Strategy
- paragraph: "How does a decision tree find the best threshold? It doesn't guess random decimals. Instead, it uses a deterministic mathematical process:"
- list:
  - strong: "Sort values:"
  - text: For a given feature (like Weight), it sorts all observed training values in ascending order.
  - strong: "Compute Midpoints:"
  - text: It calculates the halfway points (midpoints) between every adjacent pair of unique values.
  - strong: "Evaluate Splits:"
  - text: It treats each midpoint as a candidate threshold (e.g.,
  - code: Weight < 5.40
  - text: ), splits the data, and evaluates the resulting weighted Gini impurity.

- heading "Tree Stopping Rules" [level=3]:
  - text: Tree Stopping Rules
- paragraph: "To prevent the tree from growing infinitely, we define stopping constraints (hyperparameters in ML frameworks):"
- list:
  - strong: "Node Purity:"
  - text: Stop if all items in a node belong to a single class (Gini = 0).
  - strong: "Max Depth (`max_depth`):"
  - text: Stop if the path length from the root matches our limit.
  - strong: "Min Samples Split (`min_samples_split`):"
  - text: Stop if a node contains too few samples to allow another split.
  - strong: "Min Samples Leaf (`min_samples_leaf`):"
  - text: Prevent splits that leave a child with too few samples.
  - strong: "Min Impurity Decrease (`min_impurity_decrease`):"
  - text: Stop if Gini gain is below a small threshold.

- generic: Stage 15 · Reflect
- heading "Limitations & Model Choice" [level=2]: Limitations & Model Choice
- paragraph: Classification Trees are incredibly intuitive, but they are not always the best tool for every job. Understanding their trade-offs is crucial for a data scientist.
- heading "Strengths vs. Weaknesses" [level=3]:
  - text: Strengths vs.
  - text: Weaknesses
- heading "When they shine:" [level=4]
- list:
  - strong: "Explainability:"
  - text: Outputs simple rules that any non-expert can read and audit.
  - strong: "No Scaling Required:"
  - text: Features are evaluated independently, so feature magnitude does not matter.
  - strong: "Handles Mixed Types Conceptually:"
  - text: Trees can split numerical and categorical predictors, but raw categorical support depends on the software. Some libraries require encoded categories; others implement native categorical splits.
- heading "When they struggle:" [level=4]
- list:
  - strong: "High Variance:"
  - text: Extremely sensitive to tiny training set alterations, which can yield completely different splits.
  - strong: "Axis-Aligned Boundaries:"
  - text: Since splits are purely horizontal or vertical, diagonal patterns require jagged, inefficient steps.
  - strong: "Overfitting:"
  - text: Easily memorize noise if depth is unchecked.
  - strong: "Class Imbalance:"
  - text: If one class is much more common, the tree may favor that class unless class weights, resampling, or better evaluation metrics are used.

- paragraph: A leaf probability is the class proportion among training cases in that leaf. Small leaves can produce unstable probabilities, so minimum-leaf constraints and calibration may matter.
- paragraph: All pruning and hyperparameter choices must use training or validation data only. Letting the test set influence tree depth is data leakage wearing a respectable-looking branch costume.
