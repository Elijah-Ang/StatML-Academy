Imbalanced Classification

Evaluate rare outcomes using realistic prevalence, costs, and calibrated probabilities.

Stage 01

The problem

When positives are rare, a model can be highly accurate while missing every important case. Evaluation must reflect prevalence, asymmetric costs, and operational capacity.

Stage 02

Intuition and objective

The threshold converts probabilities to actions. Lower thresholds increase recall and false positives; higher thresholds usually increase precision while missing more positives. Prevalence changes predictive values even when sensitivity and specificity stay fixed.

Stage 03

Worked example

Fraud prevalence is 1%. A rule with 90% recall and 95% specificity flags 1,395 of 10,000 transactions: 90 true frauds and 1,305 false alarms. Precision is only 6.5%, so investigation capacity matters.

Stage 04

Reasoning with the method

Sensitivity and specificity condition on actual class, while precision conditions on predicted positives; therefore precision changes strongly with prevalence. A small false-positive rate can still create an overwhelming number of alerts when negatives dominate. ROC and precision–recall curves show different trade-offs and neither chooses an operational threshold automatically. Weighting changes the training objective; resampling changes the examples seen. Synthetic cases must remain inside training folds and may be implausible. Calibration may need correction after altered sampling or prior shift. Confusion counts reveal workload that rates alone can hide.

A defensible analysis connects the mathematical target to the real decision. Identify what is estimated, which observations contribute independent information, what choices are learned from data, and which uncertainty remains after fitting. Then ask how the conclusion would change under another reasonable sample, a plausible alternative specification, or a shift in the deployment population. This reasoning must happen before the final test set is opened. The test result evaluates the locked procedure; it does not choose that procedure. Sensitivity analysis is most useful when it is planned around credible failure modes rather than used to search for a preferred answer.

Stage 05

Interactive laboratory

Adjust prevalence, threshold and false-negative cost. Watch precision, recall and expected cost respond.

Stage 06

Assumptions and failure modes

Assumptions

Evaluation prevalence and case mix must match intended use. Labels and error costs must be credible; grouped or time structure must be preserved.

When the method fails

Accuracy and ROC-AUC can look healthy while positive predictions are unusable. Oversampling outside folds leaks, and resampling changes apparent prevalence and calibration.

Stage 07

Practical workflow

  1. Define positive class and action
  2. Estimate realistic prevalence and costs
  3. Use stratified plus group/time-aware validation
  4. Resample or weight inside training folds
  5. Calibrate probabilities when needed
  6. Choose threshold on validation data
  7. Evaluate once on test data

Stage 08

Interpretation and reporting

What to report: Report prevalence, confusion counts, precision, recall, specificity, PR-AUC, calibration, threshold, cost assumptions and uncertainty.

Common misuse: Balancing the test set and then reporting its precision as deployment precision.

Stage 09

Knowledge checks

A rare positive class makes accuracy…

Answer and explanation

Potentially misleading. Predicting the majority class can dominate accuracy.

Oversampling belongs…

Answer and explanation

Inside each training fold. Held-out rows must remain untouched and at natural prevalence.

Which curve often reveals rare-positive performance?

Answer and explanation

Precision–recall. PR curves focus on positive retrieval and predictive value.

Threshold choice should use…

Answer and explanation

Validation data and explicit costs. Thresholds are decision hyperparameters.

After case-control sampling, probabilities may need…

Answer and explanation

Recalibration to deployment prevalence. Sampling changes the class prior seen during training.
