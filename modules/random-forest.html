Random Forest

Average decorrelated decision trees to improve prediction stability.

PrerequisitesClassification Trees and Regression Trees

Stage 01

The problem

A single tree is interpretable but unstable. Random forests average many deliberately varied trees so individual split noise cancels while shared predictive structure remains.

Stage 02

Intuition and objective

Each tree sees a bootstrap sample and a random subset of candidate features at each split. Averaging mainly reduces variance when trees make partly independent errors.

Stage 03

Worked example

One tree classifies 82% of validation cases, but across resamples it ranges from 74% to 87%. A 300-tree forest reaches 86% with a much narrower range. The gain comes from averaging; 300 trees are not 300 independent datasets.

Stage 04

Reasoning with the method

Bootstrap samples vary observations and random feature subsets vary candidate splits. Diversity matters because averaging highly correlated trees removes less variance. Out-of-bag predictions provide a development estimate, but extensive optimisation against that estimate still needs outer evaluation. More trees reduce Monte Carlo noise; they do not cure leakage, biased sampling or drift. Permutation importance measures predictive reliance under disruption, not causality. Correlated predictors can substitute for one another, and partial dependence can average over unrealistic combinations. Leaf size and weighting also affect the smoothness and calibration of predicted probabilities.

A defensible analysis connects the mathematical target to the real decision. Identify what is estimated, which observations contribute independent information, what choices are learned from data, and which uncertainty remains after fitting. Then ask how the conclusion would change under another reasonable sample, a plausible alternative specification, or a shift in the deployment population. This reasoning must happen before the final test set is opened. The test result evaluates the locked procedure; it does not choose that procedure. Sensitivity analysis is most useful when it is planned around credible failure modes rather than used to search for a preferred answer.

Stage 05

Interactive laboratory

Adjust tree count and features considered per split. Watch out-of-bag error stabilise and tree correlation change.

Stage 06

Assumptions and failure modes

Assumptions

Training data must represent deployment, observations must respect split structure, and features must be available at prediction time.

When the method fails

Forests extrapolate poorly in regression, probabilities may need calibration, correlated predictors distort importance, and large forests cost memory and latency.

Stage 07

Practical workflow

  1. Build a simple tree baseline
  2. Place preprocessing inside resampling
  3. Tune feature sampling and leaf constraints
  4. Grow enough trees for stable error
  5. Check calibration and subgroup performance
  6. Evaluate the locked forest once

Stage 08

Interpretation and reporting

What to report: Report tree count, feature sampling, depth/leaf constraints, seed, resampling, OOB use, final metrics with uncertainty, calibration and importance method.

Common misuse: Treating impurity importance as a causal ranking of variables.

Stage 09

Knowledge checks

Bagging mainly reduces…

Answer and explanation

Variance. Averaging unstable learners reduces variance when errors are not perfectly correlated.

Random feature subsets help by…

Answer and explanation

Decorrelating trees. Less-correlated errors average away more effectively.

OOB error can be misused when…

Answer and explanation

Extensive tuning repeatedly optimises it without outer evaluation. Repeated optimisation makes the estimate part of model selection.

Permutation importance means…

Answer and explanation

Predictive reliance under a perturbation, not causality. Association, correlation and feature dependence shape importance.

A forest regression prediction outside the training range is…

Answer and explanation

Usually poor at extrapolating trends. Tree averages are built from observed leaf outcomes.
