- heading "The Whole Idea of QDA" [level=3]
- paragraph:
  - strong: Quadratic Discriminant Analysis (QDA)
  - text: is a supervised classification method. It models each class as its own independent multi-dimensional probability cloud.
- paragraph:
  - text: "Simple intuition: QDA asks:"
  - emphasis: "\"Which of these distinct class clouds does this new coordinate fit into best?\""
- paragraph:
  - text: Unlike LDA (which forces every class to share the exact same shape), QDA allows each class to have its own unique spread, stretch, and tilt. This mathematical flexibility is what creates
  - strong: curved boundaries
  - text: .
- strong: "QDA Pipeline:"
- text: Labeled data → Split Train/Test → Fit class-specific shapes → Score new test coordinates → Make prediction → Evaluate performance
