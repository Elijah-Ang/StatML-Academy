Stage 01 · The mystery

Turn a question into classes and clues.

Our job is precise: given an animal’s features, predict whether it is a rabbit, dog, or cat. Those possible answers are the classes.

The clues are the features: long ears, barking, and liking carrots. Features go in; one target prediction comes out.

Target ≠ feature. “What animal?” is the answer to learn. “Does it bark?” is evidence used to get there.
Stage 02 · Make data trustworthy

Clean the clues before counting them.

Real records arrive with Rabbit, rabbit, rabit, missing cells, impossible values, and accidental duplicates. A model does not infer what a human meant; it learns the mess literally.

Standardize labels, investigate duplicates, handle missing values deliberately, and correct wrong target labels. Then encode yes/no features as 1/0.

Stage 03 · Prepare the experiment

Choose the version that matches the data.

Naive Bayes is a family. Binary clues fit Bernoulli; counts fit Multinomial; continuous measurements fit Gaussian; category-valued clues fit Categorical.

Then use a stratified train/test split so each class keeps roughly the same share in both groups.

Features can also be mixed. In that case, give each column the likelihood that matches its own type, then multiply those feature-specific terms into the class score.

Stage 04 · Starting beliefs

First, count how common each answer is.

Before seeing a single clue, the model learns each class’s prior probability. Imagine 100 training animals: 50 rabbits, 30 dogs, and 20 cats.

P(class) = examples in class ÷ all examples

Stage 05 · Learn the clues

Ask how often each clue appears inside each class.

These within-class probabilities are the likelihoods. Among known rabbits, perhaps 90% have long ears. Among dogs, perhaps only 10% do.

P(long ears | Rabbit) = 45 ÷ 50 = 0.90

Stage 06 · The rule

Start, match, multiply.

Read the visual from top to bottom. Each vertical lane is one candidate class—Rabbit, Dog, or Cat. The prior under its name is that class’s starting chance.

For this new animal, ✓ means the clue is present and – means it is absent. The query card above the lanes repeats those clues. Each lane then asks: “How likely would I be to see this exact clue bundle for my class?”

Each bar is the probability of one observed clue inside the lane’s class. The bottom line multiplies the prior and all three clue matches.

lane score = prior × P(long ears | class) × P(no bark | class) × P(carrots | class)

Stage 07 · The “naive” leap

Pretend the clues are independent.

Once the class is known, the model acts as if long ears, barking, and carrot preference are separate clues. In reality, features can be connected—like height and weight, or the words “New” and “York.”

That assumption is often false. Yet it makes training extremely fast and can work surprisingly well, especially for text and smaller datasets.

What the model deliberately ignores
ear ↔ diet relationship sound ↔ body relationship clue interactions
Useful does not mean literally true. A simplifying assumption may still rank the correct class highest.

Stage 10 · Read the right score

Accuracy can flatter a lazy model.

If 99% of emails are legitimate, predicting “not spam” every time earns 99% accuracy—and catches no spam. Use metrics that match the cost of mistakes.

Three questions, three metrics
AccuracyHow many predictions were correct?
PrecisionWhen we flagged positive, how often were we right?
RecallHow many real positives did we find?
F1How well do precision and recall balance?
F1 = 2 × (precision × recall) ÷ (precision + recall)
Lowering a binary decision threshold usually raises recall and false positives. Raising it usually raises precision and false negatives.
Stage 11 · Tune honestly

Validate choices without peeking.

One split can be lucky. In five-fold cross-validation, every fold takes one turn as the validation group. Average the results and inspect how much they vary.

Use those folds to compare model type, smoothing alpha, feature representation, and the metric that matters. Never use the final test set to choose them.

Stage 14 · Worked example

One measurement can support two classes.

A new insect has antennae 3 units long. Both Grasshoppers and Katydids can have that length, so the measurement does not identify the class by itself.

Instead, read the height of each class’s antenna-length distribution at 3. In the lecture example, the relative heights are 10 for Grasshopper and 2 for Katydid. The taller curve says that this measurement is more typical of a Grasshopper.

Grasshopper: 10 ÷ (10 + 2) = 0.833
Katydid: 2 ÷ (10 + 2) = 0.167

Why the curves overlap: real classes share possible values. Naive Bayes compares how plausible the observed value is under each class; it does not require a perfect boundary.
Stage 15 · Mixed evidence

Categories and numbers can vote together.

Now predict whether golf will be played on a new day: Sunny, temperature 66, humidity 90, and Windy.

Outlook and Windy use counted category probabilities. Temperature and humidity are continuous, so each class uses a Gaussian curve to turn the observed number into a density. Every feature contributes one class-specific term.
