Each fruit is already labeled: it's either an Apple or an Orange. Because we have labels, this is supervised learning.

The Whole Idea of LDA

Linear Discriminant Analysis (LDA) is a supervised classification method. It uses labeled examples to learn a straight-line rule that separates classes.

Simple Idea: LDA looks for a direction (projection axis) where:
• Different class centers are as far apart as possible.
• Points inside each class are as tightly bunched (low spread) as possible.

LDA General Pipeline:

Labeled Data → Class Centers → Class Spread → Optimal Direction → Boundary → Prediction

"LDA is like looking at a messy 2D cloud of points from the best angle so the two groups look as separated as possible."

Tiny LDA Dictionary

Feature:

A measurement used to make a prediction (e.g., Sweetness or Color).

Label:

The known category of an example (e.g., Apple or Orange).

Class:

The target group we want to predict (Apple class or Orange class).

Mean (μ):

The average position or center of a class point cloud.

Variance:

How much a single feature fluctuates.

Covariance:

How two features move in relation to each other.

Scatter (S):

A mathematical measure of data spread or messiness.

Projection:

Squashing 2D coordinates down onto a single 1D axis.

Discriminant Score (δ):

A numerical score LDA computes for each class; the highest score wins!

We hold out a small test set (2 apples + 2 oranges) that the model will not see during training. The remaining 20 points are used to learn the pattern.

The test points are completely hidden until the evaluation stage. A model that only memorizes training data isn't actually smart — it's just a parrot with ambitions.

How the sets are used:

Training Set:

Used to learn means, covariance, priors, and the decision rule.

Test Set:

Used exactly once at the very end to check whether the learned rule works on unseen, new data.

Data Leakage Warning: The test set must stay absolutely hidden until final evaluation. Do not use the test set to choose features, tune settings, or adjust the model. If the test set influences training decisions, the final evaluation score becomes dishonest!

What does within-class scatter mean?

Within-class scatter tells us how messy or spread out each class is inside itself.
• If all apples are clustered tightly together, apple scatter is small.
• If apples are spread out all over the plot, apple scatter is large.

What is covariance?
Covariance tells us whether Sweetness and Color move together:
• Positive covariance: Sweetness goes up, and Color Score also tends to go up.
• Negative covariance: One goes up, while the other goes down.
• Near Zero: They do not move together in any pattern.

Understanding the Scatter Matrix:
• Diagonal entries: How much each feature varies by itself (variance).
• Off-diagonal entries: How much the two features move together (covariance).

Here's LDA's key assumption: all classes share the same covariance shape. The groups can have different centers, but their spread is assumed to be roughly the same.

So LDA pools the individual covariance matrices into one shared estimate. Watch the ellipses morph into a single shape.

Why does LDA pool covariance?

LDA assumes that the classes have similar spread shapes. Instead of keeping separate shapes for Apple and Orange, it combines them into one shared covariance estimate.

Simple meaning: Different centers, same general spread shape.

SB measures how far apart the class centers are. The further apart, the easier it is for LDA to separate them.

LDA's goal is to maximize the ratio of between-class scatter to within-class scatter:

Between-class scatter = gap between class centers

Let's contrast the two scatter metrics:
• Within-class scatter asks: "How messy and spread out is each class inside itself?"
• Between-class scatter asks: "How far apart are the class centers (means)?"

LDA's Ultimate Goal: We want the gap between classes to be BIG, and the messiness inside each class to be SMALL!

J(w) = wᵀ S_B w / wᵀ S_W w In simple terms, J(w) is maximized when: 1. Projected class means are far apart. 2. Projected class spreads are small.

What is projection and why do we do it?

Projection means dropping every 2D point (Sweetness, Color) down onto a single 1D line or direction.

This turns a 2D pair of numbers into a single 1D score:

Fruit (Sweetness, Color) → [Project] → One LDA Score

Why project? If the projected Apple scores sit neatly on one side of the line and the projected Orange scores sit on the other side, LDA has found an excellent direction for separation!

w ∝ S_W⁻¹ (μ₁ − μ₂) This isn't just the straight line between means. It also tilts to avoid the direction of maximum within-class spread.

Because LDA is linear, the boundary between classes is a straight line (in 2D). Everything on one side is classified as Apple, the other as Orange.

Discriminant Scores: Highest Score Wins

LDA calculates a separate scoring function for each class, called the Discriminant Score (δ):

δ_apple(x) = Score indicating how much point x looks like an Apple

δ_orange(x) = Score indicating how much point x looks like an Orange

For any point, LDA compares the two scores: whichever score is higher is the predicted class!

Example Fruit Prediction: (Simple illustrative example, not a live value from the current dataset) 2.31 -1.44

Since 2.31 is higher than -1.44, LDA predicts

Apple

What are priors (π_k)?

The prior probability (π_k) represents the class probability before observing its features. Priors may be estimated from training prevalence or specified externally.
• If apples and oranges are equally common, priors are equal (50% each).
• If we estimate priors from 90% apples in training, the apple score gets a prior boost, shifting the boundary slightly to favor Apple predictions.

δ_k(x) = xᵀ Σ⁻¹ μ_k − ½ μ_kᵀ Σ⁻¹ μ_k + log(π_k) Predict class k with the highest δ_k(x)

To use LDA effectively, you need to understand when it thrives and when it falls short.

LDA Works Best When:

  • Linearity: A straight-line boundary is a reasonable way to separate classes.
  • Normality: Each class looks like a symmetrical oval cloud (multivariate normal distribution).
  • Equal Spread: All classes share roughly the same spread/covariance shape.
  • Independence: Data samples are collected independently.
  • Data Volume: There are many more rows than features.
  • No Outliers: Extreme values are absent (outliers pull means away easily).

LDA Struggles When:

  • The true dividing boundary is highly curved.
  • Classes have very different shapes or spreads (e.g., one is a tight circle, the other is a giant flat ellipse).
  • There are severe outliers that skew centers.
  • You have too many features and not enough rows (overfitting).
  • Features are redundant or highly correlated (collinearity).

Alternative Methods

If LDA doesn't fit, consider these standard alternatives:

QDA (Quadratic Discriminant Analysis):

Excellent if class spreads are highly unequal.

Logistic Regression:

Also estimates class probabilities, but avoids LDA’s Gaussian class-conditional and shared-covariance assumptions.

KNN or Decision Trees:

Great for highly complex, non-linear boundaries.

Quick check · Is QDA automatically better whenever the shapes differ slightly?

No. Estimation cost can outweigh the flexibility.
