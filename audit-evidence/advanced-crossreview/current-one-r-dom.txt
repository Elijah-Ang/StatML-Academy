    - heading "Turn numeric values into intervals." [level=2]: Turn numeric values into intervals.
    - paragraph: A rule for every exact temperature would memorise the training sample and fail on a new value such as 23.6°C. One-R therefore discretises numeric values into intervals.

    - heading "Validate the whole learning process" [level=2]: Validate the whole learning process
    - paragraph: Don’t judge the model only on the final prediction. Any choice the model makes—like selecting the best feature or building rules—must be done inside the training fold, then checked on data it has not seen.

    - text: If several rows belong to the same person, device, or organisation, keep the whole group in one fold. Otherwise the model may recognise the group instead of learning a pattern that generalizes.
