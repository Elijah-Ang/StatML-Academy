01The Raw Target

What are we predicting?

A regression tree predicts a number. It asks questions about the inputs, such as whether a value is below a cutoff. The final group, called a leaf, returns an average learned from its training rows.

03The Clumsy Guess

Why start with the mean?

Before any split, all training rows are in one group, the root. If we predict the same number for everybody, the training average gives the smallest total squared error.

SSE4 + 0 + 4 = 8

Why this works · a little deeper

For squared error, the best constant is the mean. Move a trial constant away from that mean and total squared gaps grow. The root average is a baseline, not a prediction that every outcome really equals that value. Calculate it from the current training rows. It changes when those rows change.

Quick check · Which constant minimizes squared error here?

The mean, 4.

04The First Split

How can one question improve the prediction?

A split divides one group into two. Each side gets its own training average. This can reduce squared errors by giving different predictions to groups with different outcomes.

This notebook sends values equal to the cutoff to the left: x≤cutoff. The other side uses x>cutoff. Each child mean uses only its own training rows. In two inputs, the cut spans the current parent's region, not every unrelated branch's region.

Next: The Error Engine (RSS) ↓
05The Error Engine (RSS)

How is a split scored?

Count the squared errors inside both child groups and add them. Compare that total with the original group's error. A larger reduction is a better split under this scoring rule.

A small example · separate from the live dataset
Follow the ideaRead it in plain language
Parent SSE100
Children SSE30 + 20
Improvement50

Your notebook: Open the visual to inspect the current calculation.

↳
Try it

Keep a candidate cut fixed. Compare its child sample sizes, residual spreads and weighted impurity with the original parent.

Why this works · a little deeper

SSE, also called RSS here, is the sum of squared residuals. Split improvement = parent SSE − (left SSE + right SSE). A child-variance average must be weighted by child sizes to correspond to this total. A low training score is not yet evidence about new-data prediction.

Quick check · If children SSE equals parent SSE, what is the gain?

Zero.

Next: Recursive Splitting ↓
07Recursive Splitting

What makes the process recursive?

After splitting, ask the same kind of question inside each child. This repeated procedure is called recursion. Stop when a limit is reached or no allowed split improves the score.

A small example · separate from the live dataset
Follow the ideaRead it in plain language
StartOne node
RepeatSplit each eligible child
StopDepth, leaf size, or no useful split

Your notebook: Open the visual to inspect the current calculation.

↳
Try it

Reveal one more split level. Notice how a child’s cut stops at the edge of its own region.

Why this works · a little deeper

Each child repeats the search using only the rows inside that child. The tree stops at its depth or sample limits, a constant outcome group, or no valid useful split. Different branches may stop at different levels. An added cut affects that local region and the corresponding branching path.

Quick check · Does every branch need the same number of splits?

No.

Next: The Overfitting Trap ↓
09The Overfitting Trap

Why can a deeper tree overfit?

A deeper tree can make tiny groups that follow training noise. Its training errors may shrink while errors on other rows get worse. Check validation instead of assuming more detail is better.

A small example · separate from the live dataset
Follow the ideaRead it in plain language
ShallowCoarse partitions
DeepFiner partitions
RiskUnstable small-leaf averages

Your notebook: Open the visual to inspect the current calculation.

↳
Try it

Increase maximum depth. Compare the training and validation curves; a better training fit need not improve held-out error.

Why this works · a little deeper

Growing very deep may isolate rows when suitable splits exist, but does not always achieve zero error when identical inputs have different outcomes or growth rules constrain it. More depth improves allowed training fit, not necessarily validation. Real validation curves need not have one clean turning point.

Quick check · Can training SSE rise when an unconstrained split improves the fit?

No, but validation error can rise.

10Stopping Rules

Which stopping rules constrain growth?

Stopping rules prevent further growth. Maximum depth limits the number of questions on a path. Minimum leaf size prevents very small final groups. Choose these limits using development evidence.

max_depth limits path length. min_samples_leaf requires enough rows in each child. These are settings, not scientific constants. Compare the same candidate fits under suitable validation. If useful performance is similar, a stated simpler-model preference can be reasonable; it is not a universal law.

11Pruning: Let It Grow, Then Cut It Back

How does pruning differ from stopping early?

Post-pruning starts with a larger tree, then removes branches. Early stopping prevents those branches being grown in the first place. Both control complexity, but they compare different possible trees.

Cost-complexity pruning trades fitted training risk against the number of leaves. The α setting increases the cost of keeping branches. The live pruning comparison starts from one fixed grown tree, so it removes existing branches rather than secretly regrowing a different one. Choose α using development data.

12Trees vs. Lines

When does a tree differ from a line?

A line changes smoothly with an input. A tree gives one fixed number inside each leaf, then jumps at a boundary. A tree can represent combined input conditions, but does not extend a smooth trend beyond training data.

Why this works · a little deeper

Hold the other input fixed when comparing a line-model slice with tree steps. The original observations still have their own second-input values. A smooth truth does not guarantee the line wins; model form, data and evaluation matter. Leaf-mean regression trees predict within the training outcome range and do not extrapolate a new trend.

MAE is the average size of the errors, ignoring their signs. MSE averages squared errors, giving large misses more weight. Report which rows supplied the score and compare it with a simple baseline.

Why this works · a little deeper

MAE uses outcome units. MSE uses squared outcome units. RMSE takes the square root of MSE to return to outcome units, while emphasizing large errors. Report the sample size, split and baseline with the score. A single RMSE is not a guaranteed bound on every future error.

15Reality Check: Limitations

What are the characteristic failure cases?

A single tree can change sharply with small data changes. Small leaves can overfit. Deep paths can also become hard to explain. Outside the measured range, leaf averages do not continue a rising or falling trend.

Why this works · a little deeper

Axis-aligned trees test one input at a time, so diagonal patterns may need many rectangular steps. Their instability can make one fitted explanation fragile. Ensembles may reduce some variability but can still overfit, leak data or fail after a population change. Use comparable validation before choosing an alternative.
