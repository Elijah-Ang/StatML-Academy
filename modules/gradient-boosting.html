Gradient Boosting

Build an additive model by repeatedly correcting current prediction errors.

Stage 01

The problem

Instead of averaging independent trees, boosting builds a sequence in which each new weak learner targets the current model’s loss gradient.

Stage 02

Intuition and objective

Learning rate controls how much each tree contributes; tree count controls how many correction steps occur. Small learning rates often need more trees, so these settings must be tuned together.

Stage 03

Worked example

At learning rate .3, validation loss falls quickly then rises after 60 trees. At .05 it improves more slowly and reaches a better minimum near 300 trees. Early stopping chooses the round from validation data, not the test set.

Stage 04

Reasoning with the method

Boosting creates an additive predictor by fitting each learner to a negative loss gradient. For squared error this resembles residual fitting, but other losses create different pseudo-residuals. Learning rate scales contributions, tree depth limits interactions, and row or feature subsampling regularises. These settings interact, so learning rate and round count must be tuned together. Training loss normally keeps falling and cannot select stopping. Validation-based early stopping is a hyperparameter choice. Class weighting changes the objective and can damage calibration. Gain importance and attribution methods explain the fitted model, not a causal mechanism.

A defensible analysis connects the mathematical target to the real decision. Identify what is estimated, which observations contribute independent information, what choices are learned from data, and which uncertainty remains after fitting. Then ask how the conclusion would change under another reasonable sample, a plausible alternative specification, or a shift in the deployment population. This reasoning must happen before the final test set is opened. The test result evaluates the locked procedure; it does not choose that procedure. Sensitivity analysis is most useful when it is planned around credible failure modes rather than used to search for a preferred answer.

Stage 05

Interactive laboratory

Move learning rate and tree count. Compare stylised training and validation loss and identify underfitting versus overfitting.

Stage 06

Assumptions and failure modes

Assumptions

The loss must match the target and decision; validation must reflect deployment; preprocessing and early stopping must stay inside development data.

When the method fails

Too many rounds chase noise, poor tuning overfits, probabilities may be miscalibrated, and importance is unstable under correlated predictors.

Stage 07

Practical workflow

  1. Choose loss and baseline
  2. Create a leakage-safe validation scheme
  3. Tune learning rate, complexity and subsampling jointly
  4. Use validation-based early stopping
  5. Assess calibration and subgroup error
  6. Evaluate the locked model once

Stage 08

Interpretation and reporting

What to report: Report implementation, loss, learning rate, selected round, tree constraints, subsampling, early-stopping rule, resampling, metrics, calibration and uncertainty.

Common misuse: Choosing the number of trees from the final test-loss minimum.

Stage 09

Knowledge checks

Lower learning rate usually needs…

Answer and explanation

More boosting rounds. Each learner contributes less, so more steps are needed.

Early stopping should use…

Answer and explanation

Validation data. It is a hyperparameter choice and belongs in development.

Training loss falls while validation rises means…

Answer and explanation

Overfitting. The model is fitting training-specific detail.

For probabilities also inspect…

Answer and explanation

Brier score and calibration. Ranking and hard-label accuracy do not guarantee probability quality.

Boosting importance proves…

Answer and explanation

Neither causality nor unique importance. It is a model-dependent predictive summary.
